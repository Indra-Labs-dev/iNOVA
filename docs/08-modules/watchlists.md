# Watchlists & Intelligent Alerts

**Status:** [PLANNED] — Future
**Owner:** Archange Elie Yatte
**Last Updated:** 2026-08-08

## Purpose

Let users monitor topics without being flooded with raw notifications.

## Scope

Product-level module description.

## Capabilities

User-defined watchlists (e.g. Cybersecurity: CVE, OWASP; AI: models, providers; Development: Flutter, Python, FastAPI, Docker; Custom keywords). System aggregates and prioritizes: *"iNOVA found 37 new items. 3 require your attention: [CRITICAL]/[IMPORTANT]/[TRENDING]."*

## Dependencies

[News Intelligence](news-intelligence.md), [Cybersecurity Hub](cybersecurity-hub.md), [Knowledge Graph](knowledge-graph.md).

## Security considerations

Alert prioritization logic must not suppress genuinely critical items for engagement reasons — see [product-philosophy.md](../00-overview/product-philosophy.md) on avoiding manipulation.
