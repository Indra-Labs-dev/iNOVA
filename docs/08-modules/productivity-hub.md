# Productivity Hub

**Status:** [PLANNED] — Phase 7
**Owner:** Archange Elie Yatte
**Last Updated:** 2026-08-08

## Purpose

Help the user organize tasks, calendar, notes, and goals.

## Scope

Product-level module description. Agent-level detail is in [ProductivityAgent](../07-agents/agents/productivity-agent.md).

## Capabilities

Tasks, calendar, notes, goals, reminders, habits, focus sessions, project management, personal planning. Example: *"Organize my day"* → iNOVA inspects permitted context, proposes a schedule, asks for confirmation before creating/modifying important records.

## Dependencies

[ProductivityAgent](../07-agents/agents/productivity-agent.md).

## Security considerations

Confirmation required before modifying existing important records (see [07-agents/permissions.md](../07-agents/permissions.md)).
