# OSINT / Public Intelligence Hub

**Status:** [PLANNED] — Future, after Phase 6
**Owner:** Archange Elie Yatte
**Last Updated:** 2026-08-08

## Purpose

Legitimate, defensive public-source intelligence gathering.

## Scope

Product-level module description. Agent-level detail is in [OSINTAgent](../07-agents/agents/osint-agent.md).

## Capabilities

DNS information, public certificate information, domain metadata, public technology information, public GitHub information, public reputation information, public threat intelligence, public news correlation.

## Boundaries

Intended for legitimate research, defensive security, investigation, and authorized assessment only. Never designed around unauthorized access or exploitation.

## Dependencies

[OSINTAgent](../07-agents/agents/osint-agent.md), external OSINT data providers (Shodan, WHOIS, DNS APIs — see [iNOVA_CAHIER_DES_CHARGES.md §5.2](../../iNOVA_CAHIER_DES_CHARGES.md)).

## Security considerations

Same authorization boundary as [Cybersecurity Hub](cybersecurity-hub.md) — passive/public data only.
