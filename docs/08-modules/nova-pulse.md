# iNOVA Pulse

**Status:** [PLANNED] — Future
**Owner:** Archange Elie Yatte
**Last Updated:** 2026-08-08

## Purpose

A visual real-time intelligence center aggregating activity across hubs.

## Scope

Product-level module description. Event mechanics are in [02-architecture/event-flow.md](../02-architecture/event-flow.md).

## Capabilities

Represents new news, AI trends, cybersecurity alerts, development updates, active agents, tasks, and system events (e.g. *"127 new items collected — AI +12 trends, Cyber +8 alerts, Dev +21 updates"*). The 3D world may react visually to important events (see [04-3d-world/interactions.md](../04-3d-world/interactions.md)).

## Dependencies

Shared event bus (see [event-flow.md](../02-architecture/event-flow.md)), [News Intelligence](news-intelligence.md), [Watchlists](watchlists.md).
