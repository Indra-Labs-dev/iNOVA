## Purpose

Define who Aira is as a character, so its behavior and visual design stay consistent across contributors.

## Scope

Character identity and personality. Visual states are in [states.md](states.md).

## Naming — confirmed

```text
Product:     iNOVA
AI Companion: Aira
```

**Aira** is the official name of iNOVA's AI mascot/companion, confirmed 2026-08-08 (see [ADR-0009](../adr/0009-mascot-naming-aira.md)). This resolves the earlier open naming question between "Nova" (used as a working name through the first documentation pass) and "Aira" (from the concept asset `mascotte-aira.png` at the repository root).

**Rule:** Aira is never used as an alternate name for the product. iNOVA is the product; Aira is a character/companion integrated into the iNOVA ecosystem — the two names are not interchangeable.
