## Why Aira matters

Aira is part of the UX, not decoration. It gives the user a continuous, legible signal of what the system is doing (thinking, working, succeeding, failing) — a substitute for the implicit feedback a human collaborator would give. See [product-philosophy.md](../00-overview/product-philosophy.md): Aira can be expressive, but never at the cost of the system being predictable and transparent.

A visual reference asset (`mascotte-aira.png`) exists at the repository root as an early concept image — it has not yet been formalized into the character document below.
