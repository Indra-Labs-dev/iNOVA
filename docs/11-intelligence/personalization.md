# Personalization

**Status:** [PLANNED]
**Owner:** Archange Elie Yatte
**Last Updated:** 2026-08-08

## Purpose

Define how the feed/digest adapts to a specific user without becoming an opaque black box.

## Scope

Final pipeline stage, after attribution.

## Principle

Personalization must be explainable and based on explicit signals (watchlists, stated interests, interaction history the user can see) — not a hidden engagement-maximizing algorithm. See [00-overview/objectives.md](../00-overview/objectives.md) Objective 3.
