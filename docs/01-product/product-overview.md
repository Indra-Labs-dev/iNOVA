## Purpose

Describe iNOVA from a product standpoint: what a user sees and does, independent of implementation.

## Scope

Covers the product as a whole. Individual capabilities are detailed starting at [08-modules/ai-hub.md](../08-modules/ai-hub.md).

## Product summary

iNOVA is a single application (web-first, Flutter-based, with an embedded 3D layer) that gives its user:

- A conversational AI companion (Aira) that can reason, use tools, and delegate to specialized agents.
- A set of functional hubs (cybersecurity, programming, news, research, learning, productivity, ...) that share one identity, one permission model, and one design language.
- A mission system to turn high-level goals into inspectable, multi-step, auditable execution.
- A futuristic 2D/3D interface where the mascot and the 3D world react to what's happening.

## Primary user value

1. **One place instead of many tools** — the user does not juggle a chatbot, a security scanner, a news reader, and a task manager separately.
2. **An AI that acts, not just talks** — within explicit, visible permission boundaries.
3. **A product that explains itself** — every AI/agent action is inspectable and reversible where it matters.

## What iNOVA is not

- Not a generic chatbot wrapper.
- Not an unrestricted automation/offensive security platform.
- Not a 3D game with an AI bolted on — the 3D layer serves the product, not the other way around.
