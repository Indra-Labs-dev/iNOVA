## Purpose

Top-level entry point into the roadmap: phase sequence and how it should be read.

## Scope

Points to [phases.md](phases.md) for detail, [mvp.md](mvp.md) for the first concrete milestone, and [v1.md](v1.md)/[v2.md](v2.md)/[future.md](future.md) for later horizons.

## Rule

This roadmap is realistic and sequential by design (see [00-overview/product-philosophy.md](../00-overview/product-philosophy.md)): architecture and security precede functionality; functionality precedes advanced visual experience. Do not start a Phase N module before Phase N-1's foundations are stable — see [PROJECT_STATUS.md](../PROJECT_STATUS.md) for what's actually done.

## Phase sequence

```text
Phase 0 — Foundation
Phase 1 — iNOVA Core
Phase 2 — Aira (Mascot)
Phase 3 — iNOVA World (3D)
Phase 4 — Agents
Phase 5 — Intelligence
Phase 6 — Cyber & Programming
Phase 7 — Ecosystem
```
